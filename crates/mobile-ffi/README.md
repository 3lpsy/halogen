UniFFI boundary shared by the Swift and Kotlin apps.

- `LocalCore` opens a profile and dispatches API requests without a listening server or local credentials.
- Media access returns confined, subscription-authorized files for native playback and artwork.
- `SyncQueue` imports stable operation IDs into the shared journal and runs the Rust sync policy against local or remote accounts.
- Library IDs and existing data paths survive migration. Closing a library invalidates earlier handles.
- Swift and Kotlin bindings are generated by `just ios-core` and `just android-core`.
