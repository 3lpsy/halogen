# Current pages

Numbered HTML contact sheets follow LiftFG's surface-folder convention. Each
sheet has an adjacent PNG, stable labels and source links. These reproduce
current behavior, including platform differences, rather than proposing a new
layout. The combined deck is `../master.html`.

| Group | Coverage |
|---|---|
| Start | Connection, Local Only empty library |
| Library | Podcasts, episodes, Discover, OPML |
| Listen | Latest, queue, playlists, episode detail, player, downloads, history |
| Settings | More, preferences, accounts, download config, local data |
| WebUI | Mobile-only menu, mobile browser dock, desktop web and desktop app |

Lower settings sections, administration, editing dialogs and every possible
error state are not exhaustively mocked. Their source remains authoritative.
Actual application captures are indexed separately in `../captures.html`.
